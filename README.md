## ✨ How I Work / 我怎么工作

- Build for real use, not demos first.
- Prefer calm, durable tools over flashy complexity.
- Treat AI as augmentation, not a gimmick.
- Start from the workflow, then design the interface.

我偏好从真实问题出发做产品，而不是先做一个“看起来很厉害”的演示。对我来说，好的 AI 产品应该能自然融入人的节奏里，降低摩擦、放大能力，而不是制造新的负担。
